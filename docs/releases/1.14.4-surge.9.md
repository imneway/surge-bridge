# Surge Bridge 1.14.4-surge.9

首个公开 APK 发布，基于 SFA / sing-box 1.14.4。**这是实验性、非官方的 Surge 配置兼容项目；只有 Snell v6 完成了代理协议的端到端验证。**

## 下载选择

- `arm64-v8a.apk`：大多数现代 Android 手机，优先选择。
- `x86_64.apk`：x86_64 设备或模拟器。
- `universal.apk`：同时包含以上两种架构，体积较大，不支持 32 位 ARM。
- `SHA256SUMS`：以上三个 APK 的 SHA-256 校验值。

Android 7.0（API 24）及以上。安装包为正式签名的 release 构建，包名 `io.github.liuw.surgebridge`，版本码 `754`；沿用已有 Surge Bridge 正式版签名，可覆盖升级。调试版使用不同包名，本 Release 不包含调试 APK。

## 本版内容

- 导入和订阅更新支持范围内的 Surge `.conf`，保留原始配置文本。
- URL 导入、手动更新、按配置选择自动更新；Rule / Global / Direct 模式。
- 可选的仅故障切换，以及按配置保存的 Android 应用包名/域名代理覆盖。
- 修复代理侧 DNS 随策略组选中 DIRECT 后走直连、超时导致连接失败的问题；为含 DIRECT 的组建立隐藏解析策略镜像。
- 启动时通过缓存规则集迁移旧运行配置，完善 DNS 地址解析与兼容性提示。

## 验证与限制

- 发布前重新运行：87 项转换器断言、22 项 Android 覆盖断言、35 项模式/故障切换断言通过；生成配置通过原生内核检查，冷缓存规则下载回归通过。
- 三个 APK 的版本、非调试标志和签名均已核验，与本地交付副本的哈希一致；检查未发现已知私人配置凭据或签名私钥被打包。
- 本次发布复用与当前应用源码一致的已有 surge.9 正式包，没有重复真机安装测试。此前设备和受控测试的具体范围见[验证记录](../validation.md)。
- 其他代理协议虽有转换路径，但未做对应代理服务的端到端验证。设备验证主要是一台 OPPO 手机和 Android 模拟器。
- 不提供完整 Surge 语义；MITM、脚本、重写等未实现，部分规则/选项会跳过并提示，部分不兼容配置会拒绝导入。DNS、GeoIP 和后台行为仍有平台差异。
- 开机恢复和定期更新受 Android/OEM 限制，不保证即时执行或可靠自动重连。原生高级功能以实际构建范围为准。
- Release 构建不提供 Debug API。安装包不附带订阅、真实节点配置或私钥，需自行导入配置。

阅读[使用说明](../README.zh-CN.md)和[兼容性限制](../compatibility.md)后使用。Google Play 下载若被原配置分流为直连，可参考文档中的按应用覆盖案例；本版不会自动改写用户的 DIRECT 策略。
